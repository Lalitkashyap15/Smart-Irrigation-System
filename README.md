# Smart-Irrigation-System
IoT-based Smart Irrigation System built using ESP32, Blynk IoT, Soil Moisture Sensor, and DHT11. The system automatically monitors soil conditions and controls water pumps, enabling real-time monitoring, remote control, and efficient water conservation.

## Features

- Automatic Irrigation Control
- Real-Time Soil Moisture Monitoring
- Temperature & Humidity Monitoring
- Remote Monitoring using Blynk IoT
- Manual Pump Control
- Wi-Fi Connectivity
- Water Conservation
- Smart Decision-Based Irrigation
- MOSFET-Based Pump Switching
- Real-Time Dashboard Visualization

## Components Used

- ESP32 Development Board
- Soil Moisture Sensor
- DHT11 Temperature & Humidity Sensor
- DC Water Pump
- N-Channel MOSFET
- 0.1µF Capacitor
- Power Supply
- Wi-Fi Network
- Blynk IoT Platform

## Tech Stack

- Embedded C++
- Arduino IDE
- ESP32
- Blynk IoT
- Wi-Fi Communication
- IoT Systems
- Sensor Interfacing

## System Architecture

1. Soil Moisture Sensor collects soil data.
2. DHT11 measures temperature and humidity.
3. ESP32 processes sensor values.
4. Irrigation decisions are made automatically.
5. Water Pump is controlled through MOSFET.
6. Data is sent to Blynk Cloud.
7. Users can monitor and control the system remotely.

## Installation

1. Clone the repository
2. Open the code in Arduino IDE
3. Install required ESP32 and Blynk libraries
4. Configure Wi-Fi credentials and Blynk Auth Token
5. Upload code to ESP32
6. Open Blynk App and monitor data
